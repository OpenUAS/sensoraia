    Detailed Description

    Camera intrinsics and Brown/fisheye distortion coefficients for ray generation.

    Parameters
    widthOutput columns in pixels.
    heightOutput rows in pixels.

    Brown intrinsics use the two rectilinear fields of view. Fisheye intrinsics derive a shared focal length from the distorted diagonal ray.
