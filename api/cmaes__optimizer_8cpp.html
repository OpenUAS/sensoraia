    Detailed Description

    Bounded CMA-ES refinement for the native reference planner.

    Starts from the greedy lattice route, searches in CMA-ES latent coordinates, transforms candidates into flight bounds, and retains the best feasible route seen. Fixed-altitude tasks omit Z from the optimizer vector.
