    Detailed Description

    Shared logging and operating-system checks for the survey executable.

    Session output is mirrored rather than redirected exclusively so interactive progress remains visible while a diagnostic trail is collected. The stream-buffer lock keeps concurrent worker messages from interleaving between the console and session log.
