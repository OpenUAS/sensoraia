    Detailed Description

    Supervise the selected system or native AI-camera owner and publish captured JPEGs.

    Persistent capture uses private session filenames and an inotify completion event so an incomplete exposure is never visible under its final name. One-shot capture is allowed only when persistent mode proves no trigger was sent; ambiguous post-trigger failures are never replayed.
