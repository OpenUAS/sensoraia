    Detailed Description

    Parse capture-route settings and evaluate the simulated flight path.

    Route interpolation is deliberately simple and deterministic: the capture generator needs repeatable positions and altitude policy, not a navigation controller. Terrain-relative and start-locked altitude are kept separate because changing the reference mid-session would corrupt map scale.
