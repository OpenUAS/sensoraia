    Detailed Description

    Crop, resample, and rotate BGRA images into the requested camera frame.

    Framing is shared by rendering and metadata generation: returning the exact crop geometry lets callers derive matching intrinsics. A single scale on both axes preserves aspect ratio, while reusable buffers avoid a second full image allocation when the input can be viewed directly.
