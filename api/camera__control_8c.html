    Detailed Description

    Serialize camera-control payloads and track bounded FC-side tickets.

    The request counter advances only after the caller confirms that the entire UART frame was admitted. This avoids phantom pending controls when a frame is rejected locally and prevents unsafe replay after ambiguous delivery.
