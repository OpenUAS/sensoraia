    Detailed Description

    Load a fixed-session source set and render its projected tiles/windows.

    The implementation owns bounded decoded-photo and rendered-block caches. Returned images own their pixel/provenance vectors; cancellation is cooperative and throws before an incomplete render can be treated as complete.
