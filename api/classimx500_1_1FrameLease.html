    Detailed Description

    Exactly-once release of a borrowed frame, including exception exits.

    The capture owner must outlive its lease. Only one lease per Camera may exist. Move transfers ownership; copies and move assignment are disabled.

    Associate borrowed evidence with exactly one release operation.

    Parameters
    viewEvidence whose backing storage is retained by owner.
    ownerBorrowed capture-owner context, alive until release completes.
    releaseCallback to recycle the held request, or NULL for an unowned view.

    Camera constructs leases before interpreting metadata so failures during extraction also release the request.

    The lease owns the right to recycle the request, not the DMA memory. Keeping that distinction avoids both full-frame copies and premature reuse.
