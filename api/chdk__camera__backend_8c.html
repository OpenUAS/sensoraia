    Detailed Description

    Adapt CHDKbridge capture and lens controls to USHER's backend contract.

    This layer resolves the configured photo directory and owns naming; the subprocess layer owns USB/camera transactions. It advertises only the controls for which CHDKbridge can return command-specific evidence.
