    Encode one YUV420 frame with optional same-exposure EXIF metadata.

    Parameters
    pathNew output path; exclusive creation never replaces an existing file.
    planesBorrowed Y, Cb and Cr starts, readable throughout encoding.
    widthPositive even image width in pixels.
    heightPositive even image height in pixels.
    strideEven luma byte stride; chroma uses half this stride.
    viewCapture evidence to embed, or NULL for a pixels-only JPEG.
    processorOptional application callback for extending the EXIF document.
    Returns
    True after encoding, flushing, file sync and close; false on metadata rejection or I/O/codec failure. Partial files created here are removed.
    Precondition
    The caller has validated dimensions, strides and accessible plane lengths.

    Metadata is prepared before opening the output or entering libjpeg's C error boundary, so a throwing embed callback leaves no partial JPEG behind.

    Encode validated YUV420 planes directly, without full-frame RGB staging.

    Use the same encoder without capture/application metadata so pixels-only callers retain identical YUV layout and output-cleanup behavior.

    Parameters
    pathNew output path; exclusive creation refuses overwrites.
    planesAccessible Y, Cb and Cr plane starts, immutable during encoding.
    widthPositive even image width in pixels.
    heightPositive even image height in pixels.
    strideEven luma byte stride, at least the width rounded up to 16; chroma uses half.
    Returns
    True after encoding, flush, file sync and close; false removes partial output.
    Precondition
    The caller has checked plane lengths and image/stride layout. This low-level encoder does not accept arbitrary unchecked external plane pointers.

    ◆ publish_frame()

    bool imx500::publish_frame ( const FrameView & view,
    const std::array< const uint8_t *, 3 > & planes,
    unsigned stride,
    const char * filename,
    const FrameProcessor & processor )

    Publish caller-validated YUV420 planes and same-exposure evidence.

    Encode first, then attempt sidecar output, then link the complete JPEG into place. The JPEG is the final publication step, but JPEG and sidecar are not one atomic transaction; callbacks must remove their own partial outputs.

    Exceptions
    std::exceptionFilesystem or processor exceptions propagate after cleanup.
    Parameters
    viewBorrowed evidence belonging to the supplied pixels.
    planesAccessible YUV420 planes retained by the caller.
    strideLuma byte stride; chroma uses half this stride.
    filenameNew absolute JPEG destination.
    processorApplication's trusted sidecar suffix and writer callbacks.
    Returns
    True when the JPEG is published, regardless of missing analysis; false when publication fails. File/processor exceptions may also propagate.
    Precondition
    Plane spans cover the declared image/stride and remain immutable for this call. Capture retains its frame lease while invoking this routine.

    Analysis failure retains a usable photograph. Publication failure removes successfully created sidecars from this operation, never an existing image.

    Warning
    JPEG and sidecars are not one filesystem transaction. Consumers must check file/exposure identity, and directory power-loss durability is not guaranteed.

    ◆ run_worker()

    int imx500::run_worker ( int argc,
    char ** argv,
    const FrameProcessor & processor,
    const char * application )

    Run the shared probe/capture/READY-SHOT-OK worker with supplied model policy.

    Return values
    0Probe/capture succeeded, or the serving input ended cleanly.
    1Runtime, output or protocol-stream I/O failure.
    2Invalid arguments, dimensions, processor contract or command syntax.

    A per-SHOT save failure emits ERROR without retrying the exposure. An exception terminates the worker after reporting the reason on stderr.

    Parameters
    argcArgument count for a capture mode, excluding saved-photo matcher modes.
    argvMode, RPK and mode-specific dimensions/destination tokens.
    processorReadiness and sidecar callbacks; never interpreted as navigation here.
    applicationDiagnostic prefix selected by the independent entry point.
    Returns
    Zero for success, two for syntax/configuration misuse, one for runtime failure.

    The worker announces READY after a fresh frame and, for detection, model-specific validation. Every SHOT leases a new exposure without replay. Standard output is protocol-only while diagnostics go to standard error.
