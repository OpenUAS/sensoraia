    Detailed Description

    Own the survey mapper's validated configuration and mode defaults.

    CLI overrides are applied before mode-specific defaults so the resulting configuration has one explicit owner and one validation path. The low-memory profile further narrows that configuration to a supported bounded workflow instead of pretending every option fits on a small board.
