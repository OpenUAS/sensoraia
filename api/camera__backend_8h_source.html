    18/**
    19 * @file camera_backend.h
    20 * @brief Shared capability and lifecycle contract for USHER camera backends.
    21 * @details USHER owns scheduling, UART admission, and common photo completion;
    22 * a backend owns only its device/process work and advertises optional behavior
    23 * through capabilities. Keeping this boundary explicit prevents a camera
    24 * adapter from silently taking over unrelated backends' capture semantics.
    25 */

    35/** @brief Backend features and shared completion ownership.
    36 * @details CAMERA_CAP_PRIVATE_IMAGE returns paths from usher_prepare_photo.
    37 * Shared completion publishes them only after all metadata writes succeed.
    38 * Direct capture callers must likewise complete or retain those private files. */

    88/**
