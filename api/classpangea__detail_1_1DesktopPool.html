    const std::function< void()> & checkpoint )
    		inline

    Run indexed work and wait for every active callback to finish.

    Parameters
    countNumber of jobs.
    operationWorker callback; invocations may overlap.
    checkpointCoordinator callback for resource and stop checks.

    Poll the checkpoint while waiting. Preserve the first failure and rethrow it only after callbacks no longer borrow batch state.

    Precondition
    One coordinator calls this method; it is not reentrant.
