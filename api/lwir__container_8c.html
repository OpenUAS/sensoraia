    Detailed Description

    Bounded thermal-marker reader; JPEG pixels are deliberately left alone.

    Walks JPEG marker segments from SOI up to the first SOS or EOI and reassembles the APP15 temperature plane written by lwir_image.c. Optionally parses the APP14 "LWIREV02" text for native geometry and identity. The walk uses one fixed 65534-byte segment buffer on the stack and copies samples straight into the caller's destination, so no heap or intermediate plane is needed.

    Defensive rules: regular files of at most 256 MiB only; every chunk is checked for signature, dimensions, offset continuity and capacity; and the file's identity, size and timestamps must be identical before and after the walk, so a file replaced or rewritten mid-read is rejected.

    Returns
    False aborts the parse: duplicate key, malformed number, or a value out of range. Unrelated keys return true and are ignored, so newer writers can add fields without breaking older readers.

    Table index drives both validation and the seen bit. Ranges: width/height and flags at most 65535, rotation a multiple of 90 up to 270, mirror/flip/legend 0 or 1, source "camera" or "replay", boot_id non-empty and shorter than its buffer, frame_sha256 exactly 64 lowercase hex digits.
