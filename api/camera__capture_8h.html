    Detailed Description

    Optional split-phase capture contract for USHER image backends.

    Separating acquisition from publication lets a driver return its camera buffers before JPEG encoding or storage finishes. Only advertise this interface when the driver actually owns the selected pixels; a queued shutter request is not a retained image. Synchronous backends need not implement these hooks.
