    Detailed Description

    Native USHER adapter for on-sensor IMX500 object detection.

    The native Spottercam worker owns capture. This adapter checks its bounded object sidecar and retains the highest-confidence box for EXIF/SODA. Missing analysis does not delete a useful photograph, and a valid empty result is not a hit. Review copies happen only after USHER has tagged the original. Shared process supervision and frame timing deliberately remain separate from detector interpretation; LOOM does not use this adapter's result semantics.
