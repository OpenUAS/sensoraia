    Detailed Description

    Map calibrated camera pixels to a local flat ground plane.

    Body and mount rotations are composed before the pinhole ray model. The cached inverse is reused across output pixels; invalid or horizon-facing rays are rejected rather than extrapolated into plausible-looking map points.
