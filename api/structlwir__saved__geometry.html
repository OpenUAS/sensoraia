    Detailed Description

    Native geometry and identity recovered from the APP14 "LWIREV02" text.

    Fields: width, height native thermal size; rotation clockwise display rotation (0/90/180/270); mirror, flip display transforms; legend whether a legend strip was drawn; camera true for source=camera, false for replay; sequence frame sequence; arrival_us host arrival time; boot_id boot identity text; frame_sha256 64 lowercase hex digits plus NUL. All are validated against the APP15 layer and the JPEG dimensions before being returned.
