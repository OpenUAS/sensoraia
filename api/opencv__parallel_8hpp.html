    Detailed Description

    Header-only C++17 cv::parallel::ParallelForAPI backend for Sensoraia.

    Replaces OpenCV's internal pthreads thread pool (parallel_impl.cpp, disabled at build time with -DWITH_PTHREADS_PF=OFF) so ext/opencv remains an unmodified upstream release tag while all multi-threaded cv::parallel_for_ regions execute without lock-free data races under both GCC and Clang.

    Worker threads are created lazily on the first parallel region that needs more than one thread, parked on a condition variable between regions to avoid per-call thread-creation overhead, and joined deterministically when cv::setNumThreads(1) is requested or when the outermost ScopedBackend guard leaves main().
