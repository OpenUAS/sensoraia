    Detailed Description

    Finite-grid GP observations, uncertainty updates, and reference route scoring.

    Despite the historical filename, this file does not train the ONNX denoiser. It maintains and queries a Gaussian-process (GP) belief about a scalar field, builds synthetic sensor operators, and provides the greedy/spline machinery used by the explicitly selected comparison planner.

    The shared linear-observation model
    For N grid cells and M sensor rows, each row of H uniformly averages its listed cells. We store those indices rather than a mostly zero M-by-N matrix. Sigma is the dense N-by-N covariance; R is diagonal independent sensor noise.
    P = H * Sigma (M by N)
    S = H * Sigma * H^T + R (M by M)
    B = solve(S, P) (M by N)
    posterior_mean = mean + B^T * (measurement - H * mean)
    posterior_covariance = Sigma - P^T * B
    Expected information gain needs the covariance update but not future measured values. That distinction lets look-ahead reduce hypothetical uncertainty without handing the planner the hidden field's answer sheet.
    When changing numerical behavior
    The Eigen branch below and the default aigenlib kernels implement the same valid-input model. Keep operator weights, grid order, solver cutoffs, and reduction rules aligned, and run differential tests when changing either. Public contracts stay in the header; implementation notes here explain why.
    Warning
    Grid construction caps N, not whole-process memory. One 2601-by-2601 double covariance is about 51.6 MiB; hypothetical copies, M-by-N workspaces, and solver allocations are additional. Some helpers assume valid inputs rather than checking every precondition in both numerical backends.
