    Detailed Description

    Bounded native lens and exposure correction for USHER JPEGs.

    Validates a versioned profile, reads the clean source JPEG and flight EXIF, renders in memory-bounded strips, and atomically publishes a derivative with provenance. Default profiles are illustrative, not measured calibration.
