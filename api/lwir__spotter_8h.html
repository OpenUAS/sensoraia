    int lwir_spotter_analyze ( const char * filename,
    const union dc_shot_union * shot,
    const struct capture_timing * timing,
    const volatile sig_atomic_t * running )

    Analyse one immutable image with copied capture evidence; no camera is acquired.

    Caller serializes calls. Geographic results require qualified exposure timing and pose; an unavailable position never invalidates a good image result.

    Parameters
    filenamePath to the published LWIR JPEG with embedded thermal evidence.
    shotCapture trigger carrying the photo number.
    timingFrame delivery and optional exposure/pose evidence for this image.
    runningCancellation flag passed to the subprocess wrapper.
    Returns
    Zero for disabled or successful analysis, minus one on failure.

    ◆ lwir_spotter_limits()

    bool lwir_spotter_limits ( const char * limits)

    Set the timing and pose uncertainty limits for projection.

    Parameters
    limitsComma-separated maximum exposure interval in microseconds and maximum pose uncertainty in metres.
    Returns
    True if both positive bounds were accepted.

    Apply both limits together after parsing, before the worker starts. They constrain geographic estimates, not pixel-space detection.
