    Detailed Description

    Native finite-grid GP sensor model and trajectory-planning API.

    Provides the reusable research/reference planner used by the explicitly selected CMA-ES comparison mode. The implementation stores dense covariance in build-selected row-major matrices, so the 2601-cell cap is a deliberate memory bound rather than an arbitrary input restriction.
