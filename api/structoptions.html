    Detailed Description

    Validated capture and reporting policy, fixed before the sample loop.

    Parsed overlay policy; all strings are borrowed from the process argument vector.

    Calibration is a caller-supplied offset, not automatic microphone calibration. It changes reported levels, not the dBFS alarm decision.
