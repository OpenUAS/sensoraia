    Detailed Description

    Validate Gregorian UTC targets and qualify simulator time samples.

    The UTC lock is based on repeated simulator clock writes and readback; it is deliberately not treated as the camera's shutter clock. Frame-age and monotonic timestamp checks prevent stale readbacks from being promoted into capture metadata.
