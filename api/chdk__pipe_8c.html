    Detailed Description

    Own and supervise bounded CHDKbridge child invocations for USHER.

    The child is launched directly, not through a shell, and remains owned until reaped. Deadlines and process-group shutdown are required because USB work can outlive a single caller; an ambiguous exposure is never replayed.
