    Detailed Description

    Public planning, synthetic-survey, and comparison APIs for Diplacam.

    The production path conditions a finite-grid Gaussian-process belief from synthetic observations and samples eight waypoints with a native DDIM loop backed by ONNX Runtime. The opt-in comparison path plans over the same belief with the native greedy/CMA-ES reference; it is not an automatic fallback. Coordinates are local east/north metres. This header intentionally exposes fixed-size production contracts while hiding Eigen, ONNX Runtime, and planner implementation state from callers.
