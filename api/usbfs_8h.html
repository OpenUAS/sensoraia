    Detailed Description

    Minimal header-only Linux usbfs access for one CHDKbridge camera.

    Discovers devices through sysfs, parses the active configuration, owns one interface and performs synchronous bulk transfers through /dev/bus/usb ioctls. The wrapper allocates no heap storage and creates no threads.

    Warning
    Serialize all access to a handle, including close. A bulk call owns its submitted URB until completion or descriptor teardown; another caller must not reap it or close and reuse the descriptor.
