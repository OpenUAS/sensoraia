    Detailed Description

    Runtime-owned ONNX session and reusable input/output storage.

    Bind once and reuse across all twenty denoising calls and later plans. This avoids rebuilding application-side tensors in the hot loop; it does not promise allocation-free execution inside ONNX Runtime.

    Invariant
    The session borrows member buffers whose addresses remain stable until the session is closed by the destructor.
    Warning
    A State is single-owner mutable workspace, not a concurrent sampler.

    Validate the export contract before binding a reusable ONNX session.

    Reject mismatched geometry, schedules, and tensors at startup, when there is still a useful file error to report, rather than after a plausible-looking but mis-scaled route reaches the application.

    Parameters
    [in]modelONNX graph path.
    [in]metadataDeployment JSON describing training-time preprocessing.
    [in]policyOptional integrity descriptor, thread count, and deadline policy.
    Precondition
    initialize_runtime() has successfully selected a compatible runtime.
    Exceptions
    std::exceptionIf reading, allocation, validation, or session creation fails.
    Note
    Parser views are temporary. Copy only checked numeric values into members; nothing in the session may borrow the constructor's JSON arena.
