    libcamera::Size image )

    Validate the model's four output tensors and project object boxes into the JPEG.

    Parameters
    tensorInterleaved boxes followed by scores, classes, and the detection count.
    infoDriver CnnOutputTensorInfo bytes for this same camera request.
    cropSensor crop reported in that request's ScalerCrop metadata.
    imageConfigured still-stream dimensions.
    Returns
    Invalid by default; valid with zero or more boxes only after full validation.

    This is intentionally model-specific. Raw neural arrays cannot be treated as boxes until shape, integral count and coordinate assumptions hold.

    BasicResult spottercam::frame_result ( const imx500::FrameView & frame)

    Interpret only the detector model's outputs from this retained exposure.

    Parameters
    frameBorrowed same-exposure tensors, crop and configured image size.
    Returns
    Invalid without crop evidence, otherwise the validated detector result.

    A guessed full-sensor crop could put correct boxes in the wrong JPEG position, so missing geometry is a failed analysis rather than a default.

    Publish detector results, never LOOM features or navigation evidence.

    Parameters
    frameBorrowed exposure whose image/tensor identity is retained by a lease.
    filenameNew analysis destination selected by the camera publication owner.
    Returns
    True after exclusive-create, flush, sync and close; false retains no partial output.

    Readiness can describe an earlier warm-up frame. Decode this frame again rather than reusing a previous result for newly captured pixels.
