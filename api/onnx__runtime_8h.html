    ◆ onnx_runtime_open()

    bool onnx_runtime_open ( const char * library_directory,
    char * error,
    size_t capacity )

    Initialize one process-lifetime runtime/environment using explicit local search roots.

    Parameters
    library_directoryOptional final search directory; NULL/empty omits it.
    errorWritable diagnostic buffer, cleared on success.
    capacityAvailable bytes in error, including its terminator.
    Returns
    True after initialization or when this process already owns a runtime.

    The first existing candidate must work; falling back would hide broken packages. The library and environment stay alive so sessions never retain unloaded API pointers.

    Note
    Concurrent initialization is serialized; later calls reuse the selected runtime.
