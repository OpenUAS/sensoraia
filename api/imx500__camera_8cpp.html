    Detailed Description

    Shared IMX500 capture, frame ownership and JPEG publication mechanics.

    Camera ownership and model interpretation deliberately have separate lifetimes. Retaining one request keeps its pixels, crop, tensors and timestamps together without another image queue. Application callbacks decide what those tensors mean; this implementation only captures and publishes their evidence. The owner serializes camera operations and lease destruction; libcamera's completion callback uses a mutex only for the handoff, not for image processing.
