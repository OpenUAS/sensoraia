    ◆ jsonbourne_read_limits

    typedef struct jsonbourne_read_limits jsonbourne_read_limits

    Per-read budgets checked during validation, before a DOM is allocated.

    Limits are literal upper bounds: zero permits none of the resource, not an unlimited amount. Start with jsonbourne_read_limits_default() so a partially initialized structure cannot accidentally prohibit useful input.

    ◆ jsonbourne_str_loc

    typedef struct jsonbourne_str_loc jsonbourne_str_loc

    String view followed by optional source coordinates.

    Precondition
    Only cast a parsed string/key to this type when TRACK_LOCATION was enabled.

    Keeping the base first preserves ordinary string access while making location storage opt-in rather than charging every node for coordinates.

    ◆ jsonbourne_read_flag_e

    enum jsonbourne_read_flag_e

    Independent reader options and convenience presets.

    Presets are unions of feature bits, not distinct parser modes. Use the names rather than persisting raw masks so code can follow flag remaps.
