    Detailed Description

    Fixed-memory geometric coverage accounting, independent of camera I/O.

    This layer compares footprints rather than decoding photographs. Keep predicted observations separate from committed coverage: only the capture owner knows whether an original and its metadata were successfully published.

    Note
    Functions do not lock. Serialize access to a shared state at the caller. Invalid geometry means "unknown", never "already photographed".

    Choose the first observation of the best feasible one- or two-shot plan.

    Parameters
    stateCommitted coverage, left unchanged.
    candidatesAt most COVERAGE_CANDIDATES opportunities.
    countNumber of opportunities.
    now_usEarliest permissible start, monotonic microseconds.
    service_usPositive serialized acquisition interval used between choices.
    Returns
    First candidate index, or -1 when no positive feasible gain is known.

    Union scoring avoids double-counting repeated ground in the second view. Ties favor an earlier start, then greater first-shot gain. The caller still enforces overlap, uncertainty and delay limits; this is not a global flight planner.
