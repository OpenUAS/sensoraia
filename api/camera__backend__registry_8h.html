    enum camera_backend_type preferred,
    bool local_only )

    Resolve a physical ID, preferring its configured logical profile.

    Parameters
    camera_idStable protocol identity; unsupported IDs are rejected.
    preferredConfigured profile, used only for its own physical camera.
    local_onlyReplace image acquisition with the generic local driver.
    Returns
    Profile to acquire, or CAMERA_BACKEND_UNSELECTED if unavailable.

    Identity is resolved separately so local acquisition never erases the requested sensor's naming, geometry or metadata policy.
