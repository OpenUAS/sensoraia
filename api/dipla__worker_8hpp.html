    Detailed Description

    Public entry point for Diplacam's bounded local IPC worker.

    The worker receives fixed-size requests over a connected Unix socket, keeps a bounded ordered observation FIFO, and returns immutable route snapshots or pinned legacy point slots. Transport details and synchronization state remain private to the implementation.
