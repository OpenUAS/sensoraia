    Detailed Description

    Plan interoperable XYZ tile ranges in Web Mercator.

    XYZ uses a north-origin tile grid and the Web-Mercator latitude limit. Planning snaps only floating-point noise at exact tile boundaries so a request does not gain or lose an entire row of tiles from rounding error.
