    Detailed Description

    Turn a synthetic survey's GP belief into eight model or comparison points.

    Three responsibilities deliberately meet here without becoming one algorithm:

    • Survey owns the hidden field and Gaussian-process (GP) posterior. Only a sensor footprint may reveal truth; planners receive the resulting belief.
    • Network adapts that belief to the exported ONNX denoiser and performs the complete deterministic DDIM reverse process, returning raw XYZ in metres.
    • apply_flight_margin() prepares either planner's route for publication, without changing the sampler's numerically testable model contract.

    The flight controller, not this file, decides when a route has been flown. Keeping inference, flight preparation, and mission progress separate lets us compare the sampler with the Python reference without importing flight policy into the maths. There is one neural network here, not a second flight network.

    When adapting a model
    Grid geometry, axis order, world scaling, tensor bindings, normalizations, and the diffusion schedule form one contract. Update and test them together; a tensor with the right shape can still describe entirely the wrong world.
    Warning
    Reused network tensors and mutable survey state require serialized ownership. Fixed tensor buffers do not make ONNX Runtime or the GP heap-free; the dense covariance alone occupies about 51.6 MiB.
