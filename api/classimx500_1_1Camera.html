    Detailed Description

    One exclusive IMX500 owner with bounded reusable YUV420 buffers.

    Precondition
    Control operations and lease destruction are serialized by their owner; the camera's callback thread is synchronized internally.

    FrameLease imx500::Camera::capture ( )

    Lease a fresh post-request exposure and its own tensor metadata.

    Returns
    Move-only lease; destroy it before the next capture or camera shutdown.
    Exceptions
    std::runtime_errorfor missing startup, a still-live prior lease, queue failure, unavailable clock or frame timeout.

    Freshness uses the sensor/BOOTTIME domain, not JPEG download time. Model-specific validation remains the processor's responsibility.

    A queued frame can predate a SHOT command. Compare sensor timestamps in the BOOTTIME domain instead of treating callback arrival as exposure time. Tensor validity and interpretation remain the application's responsibility.

    Acquire one eligible camera and configure bounded capture, uploading an RPK only when requested.

    Parameters
    modelReadable RPK for IMX500 inference, or NULL for plain pixels.
    widthRequested JPEG width, not model-input width.
    heightRequested JPEG height, not model-input height.
    photo_onlySelect IMX500 image-only capture and leave frame duration to libcamera.
    Exceptions
    std::runtime_errorfor unavailable/ambiguous hardware or rejected configuration.

    Configuration adjustments that change our expected geometry, YUV420 layout or buffer budget are rejected rather than silently changing downstream assumptions.

    Exactly one eligible camera is required so discovery order cannot silently choose a different sensor. Partial startup remains owned by Impl and is unwound when the Camera is destroyed.

    ◆ save()

    bool imx500::Camera::save ( const FrameLease & frame,
    const char * filename,
    const FrameProcessor & processor )

    Map a leased frame and publish its JPEG plus available evidence.

    Parameters
    frameLease obtained from this camera, still alive and unmoved.
    filenameNew absolute JPEG destination; existing images are not overwritten.
    processorApplication-owned sidecar policy for this same exposure.
    Returns
    True after JPEG publication, false for rejected layout/path or write failure.

    Mapping is scoped separately from the lease: CPU DMA ownership ends before the request can be recycled. Missing analysis does not discard good pixels.

    Warning
    Success is not proof of a useful neural match, geolocation accuracy, complete multi-file crash atomicity or parent-directory power-loss durability.

    with_pixels() scopes CPU/DMA access around publication; the caller still owns the frame lease and decides when the request returns to the queue.

    Exceptions
    std::exceptionMapping, filesystem or processor failures may propagate.

    Parameters

    contextBorrowed callback state, not retained by the camera.
    Returns
    Callback result, or false for invalid ownership/layout/visitor.
    Precondition
    The visitor must not retain pixel pointers or release the lease during the call.

    Prepare a model-sized tensor here, then release the lease before expensive inference.

    Plane allocation sizes alone do not prove that a frame produced enough bytes. Check bytesused before exposing chroma, and unmap/end CPU access before returning or unwinding to the code that can recycle the request.
