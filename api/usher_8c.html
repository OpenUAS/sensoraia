    Detailed Description

    Main USHER daemon coordinating flight-controller triggers and camera backends.

    The event loop receives validated UART frames, queues bounded capture jobs, dispatches backend work on detached workers, records metadata, and returns status. It deliberately keeps serial I/O separate from slow camera processes so one capture cannot block command reception. Backend failure is isolated per camera wherever possible; systemd owns whole-daemon restart for irrecoverable transport failures.

    Ownership at a glance
    The event loop owns protocol dispatch and survey admission. Optical tickets serialize CHDK/AIcam access; live LWIR has a separate worker and recovery lock. A split-phase image retains its backend completion table after the optical lane is released. Live SODA uses a separate single worker and owns filenames only. Keep these boundaries distinct: accepting a trigger, owning pixels and saving a geotagged original are three different events.
    Warning
    Bounded workers prevent software backlog growth; they do not isolate shared power, storage, kernel stalls or the whole board's memory consumption.
