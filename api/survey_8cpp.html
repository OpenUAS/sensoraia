    Detailed Description

    Command-line entry point for completed-session PANGEA mapping.

    Survey processing consumes saved photos and validated session metadata; it is not part of the camera trigger path. Separate per-user locks exclude both another survey and the live PANGEA worker so two independent consumers cannot compete for memory or checkpoint files.
