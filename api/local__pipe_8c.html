    Detailed Description

    Hardware-free camera backend for fixture copies and cached map views.

    Use the requested camera identity for naming while keeping simulation outputs distinct from hardware captures. Map rendering delegates projection and publication to the shared image workspace. Fixture mode copies an existing image without recoding it.
