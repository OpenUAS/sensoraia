    21/**
    22 * @file lwir_cam_pipe.h
    23 * @brief Parent-side protocol for USHER's persistent Tiny1-C LWIR capture server.
    24 * @details USHER uses this interface to keep the thermal stream warmed between shots.
    25 * A line protocol carries capture and geolocation requests; the implementation handles
    26 * bounded server lifecycle, response validation, and capture timing evidence. USHER's
    27 * recovery worker owns retry policy.
    28 */
