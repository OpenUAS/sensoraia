    Detailed Description

    Model-identified feature transport independent of IMX500 tensor metadata.

    Fixed little-endian fields preserve float bits and feature-space identity across PC/ARM64.

    Encode a complete LOOMOX01 record without fabricating an IMX500 metadata header.

    Parameters
    recordWritable destination, unchanged when validation rejects the input.
    capacityAvailable bytes; records cannot exceed LOOM_ONNX_FEATURE_CAPACITY.
    modelCompleted immutable float outputs and their exact graph/descriptor identities.
    sequenceSource correlation, retained separately from any flight-controller shot number.
    sensor_timestamp_nsPhysical sensor time when available; zero explicitly means unavailable.
    Returns
    Encoded byte count, or zero for invalid/nonfinite/oversized features.
    Precondition
    Input tensors and destination do not overlap. This transport does not establish a visual match.
