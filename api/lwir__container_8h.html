    Detailed Description

    Exact thermal evidence in JPEG containers, independent of analysis.

    Read side of the format written by lwir_image.c. A saved LWIR JPEG keeps the native temperature plane, little-endian Kelvin*64 per sample, in APP15 chunks signed "LWIRRAW1" (live camera) or "LWIRSIM1" (synthetic replay). Because those bytes bypass the lossy DCT path, temperatures read back here are bit-identical to the captured plane at any JPEG quality.

    Used after capture by analysis, geolocation and validation tools that need temperatures from a stored photo. Only marker segments up to the first scan are parsed; compressed pixels are never decoded.

    Invariants enforced by the reader:

    • Chunks share one signature kind and one width/height, and their offsets are contiguous from zero; the layer must be complete.
    • Native dimensions are independent of display orientation.
    • The file must be a regular file that does not change while being read.
    • Image-only JPEGs (TDK layout) have no layer: the layer/stream readers return 0 for them.

    Enumeration Type Documentation

    ◆ lwir_thermal_layout

    enum lwir_thermal_layout

    Existing APP15 wire layout, shared by the reader and image writer.

    The eight-byte signature is followed by little-endian uint32 width, height and byte offset into the native temperature plane. Samples start at byte 20. Chunk capacity is the writer's policy, not a reader acceptance limit.

    Extract the temperature plane plus its recorded provenance geometry.

    Parameters
    filenameRegular JPEG path; symlinks are refused (O_NOFOLLOW).
    destinationCaller-owned sample storage; ignore on failure.
    capacityWritable bytes in destination.
    geometryWritten only on a complete, consistent result.
    Returns
    1 for a complete layer with matching APP14 evidence, otherwise -1 (invalid input, missing or duplicate APP14 evidence, any inconsistency, or I/O failure).

    Stricter than lwir_read_temperature_layer(): exactly one LWIREV02 record with all eleven geometry keys must be present; its native size must equal the layer, its source must match the signature kind, and the JPEG dimensions must equal the native size after the recorded rotation.

    Note
    Never returns 0: without a layer the geometry cross-checks cannot pass, so image-only or layer-less JPEGs report -1 here.

    Extract the temperature plane plus its recorded provenance geometry.

    O_NOFOLLOW refuses a symlinked final component; O_NONBLOCK keeps a FIFO from blocking the open so the regular-file check can reject it. Results go through locals and are copied out only on success.
