    Detailed Description

    Bounded, north-up acoustic evidence rendering and JPEG georeference sidecars.

    Deposit measured linear power into a height-dependent Gaussian grid, normalize by deposited weight, then display the loud end of the dB range. Smoothing is a visualization heuristic, not a measured microphone beam model. The decorated image explains the track; the undecorated field supports overlays.
