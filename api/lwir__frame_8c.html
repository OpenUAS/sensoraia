    Detailed Description

    Frame geometry, structural/live qualification and native temperature measurements.

    Operates on borrowed Tiny1-C combined frames: YUYV image plane (Y0 U Y1 V per pixel pair) followed by a thermal plane of little-endian uint16 Kelvin*64 codes, where 0 and 65535 are endpoint/invalid codes. Everything is in native, unrotated coordinates; display orientation and correction profiles (lwir_render.c) never affect these results.

    Pipeline role: capture calls lwir_frame_capture_valid() to drop camera transition fill and frames without temperatures; lwir_frame_plausible()/lwir_frame_settled() are optional heuristics; lwir_measure_temperature() serves point, line and rectangle requests.

    The scalar measurement code is the reference. On little-endian ARM64 NEON handles eight-pixel rectangle blocks with identical results: exact rounded integer averages, first-occurrence extrema and the same coverage counts (parity-tested). No heap is used.

    bool lwir_frame_plausible ( const uint8_t * frame,
    size_t bytes,
    unsigned width,
    unsigned height )

    Conservative scene-plausibility heuristic.

    Optional conservative scene check; unusual valid scenes may be rejected.

    1. Chroma: every odd image byte is U or V; more than 1% outside 128 +/- 8 fails.
    2. Roughness: sum of |Y(x) - Y(x+1)| must average at most 45 per adjacent pair.
    3. Temperature: every eighth thermal sample; more than 10% outside raw 14000..40000 (about -54..352 degC, endpoint codes included) fails.
      Returns
      True when all checks pass. Unusual but genuine scenes may fail.

    Measure a point, line or rectangle in native coordinates.

    Measure apparent device temperatures, keeping diagnostic coverage separate.

    Lines use integer Bresenham traversal of every center from start to end inclusive. Rectangles are visited in raster order; on ARM64 NEON handles eight-center blocks and scalar code handles the first column (when averaging), the right border and the tail. Results are built in a local copy and published only on success.

    Returns
    False for NULL pointers, invalid request/geometry, size mismatch or an empty threshold band; errno is not set.

    Measured value of one center, optionally 3x3-averaged.

    Averages the valid (non-endpoint) codes of the 3x3 neighbourhood clipped at the sensor edges, rounded half up: (sum + n/2) / n. The valid center guarantees n >= 1.

    Parameters
    planeThermal plane start.
    widthNative width.
    heightNative height.
    columnCenter column.
    rowCenter row.
    averageWhether averaging is requested.
    centerThe center's raw code.
    Returns
    center unchanged when not averaging or when it is an endpoint code; otherwise the rounded mean, which stays within 1..65534.
