    Detailed Description

    Own LOOM's AIcam specialization outside the universal USHER service.

    The capture owner and saved-photo worker have separate lifecycles: optional matching starts without acquiring IMX500, while physical capture is lazy. A failed matcher never disables ordinary photograph capture.

    Configure the LOOM plugin before selecting or initializing its owner.

    Parameters
    referencesBorrowed reference-directory path, valid until initialization.
    modelBorrowed RPK path, valid for the capture backend lifetime.
    Precondition
    No LOOM owner is active while configuration changes.

    Saved-photo worker initialization copies its paths; native capture continues borrowing the model until shutdown. Do not shorten that lifetime merely because the matcher has already started.
