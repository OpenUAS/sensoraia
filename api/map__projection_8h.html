    Detailed Description

    Convert between WGS-84 coordinates and one local UTM grid.

    Map pixels are laid out in metres in a single zone so resampling and world-file spacing stay linear across a small survey. Inputs outside the supported UTM latitude, hemisphere, or zone span are rejected rather than silently producing a plausible-looking but invalid grid.
