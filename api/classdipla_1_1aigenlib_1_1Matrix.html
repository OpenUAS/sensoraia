    Detailed Description

    Owning, contiguous, row-major double matrix.

    Each extent is at most max_extent. Construction checks before multiplying dimensions. Element/row access is checked, including release builds. A borrowed row pointer is valid until assignment, move, or destruction; callers must bound column accesses. Moved-from matrices are empty 0-by-0.
