    Detailed Description

    template<class Number>
    class Aigen::Matrix4< Number >

    Owning, zero-initialized 4-by-4 column-major value matrix.

    Storage is sixteen scalars on the stack; products return owning values and support aliasing assignments without expression-lifetime issues. This subset provides initialization, access, transpose, trace and products, not decompositions or a general Eigen expression API.
