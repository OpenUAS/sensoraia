    Detailed Description

    Resample the UTM source mosaic into complete 256-pixel XYZ tiles.

    Tile pixels are transformed through geographic coordinates instead of assuming UTM and Web Mercator share a grid. Every interpolation tap with a nonzero weight must have source support; publishing partial or fabricated pixels would break opaque-tile compatibility and misstate coverage.
