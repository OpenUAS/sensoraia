    Detailed Description

    Measured display-correction profile for one camera, gain label and geometry.

    Applied only when rendering; raw frames and measurements are unaffected. Corrected value = round(raw * scale_ppm / 1e6) + offset_mk * 64 / 1000 (truncated), in the same Kelvin*64 units as raw samples.
