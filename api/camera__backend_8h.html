    Detailed Description

    Shared capability and lifecycle contract for USHER camera backends.

    USHER owns scheduling, UART admission, and common photo completion; a backend owns only its device/process work and advertises optional behavior through capabilities. Keeping this boundary explicit prevents a camera adapter from silently taking over unrelated backends' capture semantics.

    Backend features and shared completion ownership.

    CAMERA_CAP_PRIVATE_IMAGE returns paths from usher_prepare_photo. Shared completion publishes them only after all metadata writes succeed. Direct capture callers must likewise complete or retain those private files.
