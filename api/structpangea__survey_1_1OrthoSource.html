    Detailed Description

    One fixed-session source image and its camera/pose evidence.

    Coordinates are WGS-84 degrees; elevations are AMSL metres; camera intrinsics are pixels; timestamps are 100 ns monotonic counts. The optional capture cell lets Great use the planned flight grid without inventing pose data.
