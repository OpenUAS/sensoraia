    Parse one flat INI, delegate application keys and resolve paths against the selected file.

    Parameters
    settingsInitialized destination; discard partially parsed values on failure.
    filenameSelected settings file, independent of the caller's current directory.
    extraOptional handler for application-specific fields.
    contextBorrowed extra-handler state, used only during this call.
    errorWritable failure diagnostic, cleared on success.
    capacityAvailable bytes in error.
    Returns
    True for valid bounded syntax, accepted fields and resolvable lexical paths.

    AUTO resolves .onnx/.rpk suffixes and an omitted ONNX descriptor to the same-name .ini. It does not test availability or fall back after errors.
