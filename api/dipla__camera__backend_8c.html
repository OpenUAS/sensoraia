    Detailed Description

    Nonblocking USHER-to-Diplacam process admission and reply supervision.

    Only the native worker owns field truth, GP state and inference. This adapter keeps the UART owner responsive by sending bounded local packets and publishing correlated completed replies, never waiting for a new plan.

    bool poll_result ( struct camera_point_result * point)
    		static

    Drain a bounded reply batch and publish only the active request's result.

    Parameters
    pointDestination changed only for a complete correlated reply.
    Returns
    True for a completed valid or invalid point, false for no eligible reply.

    MSG_TRUNC detects oversized packets instead of accepting their prefix. The sixteen-packet work limit prevents stale traffic monopolizing the event loop. Credit and point packets may arrive in either order. Point completion does not wait for assimilation, and credits never become FC camera results. Quality 1000 denotes a valid computation, not physical accuracy.

    bool reap_child ( unsigned timeout_ms)
    		static

    Closing the channel prevents a late completion from reaching a new session. The polling grace permits ordinary teardown; SIGKILL contains a worker that does not respond. This is supervision, not a real-time guarantee.
