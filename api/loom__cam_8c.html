    Detailed Description

    Fresh-first saved-image requests to the standalone loomcam process.

    The AI camera remains owned by its existing driver. This adapter owns only paths, one pending request, one joinable worker and one completion mailbox. It never sends UART or mutates flight waypoints. Return vectors are validated, but archived reference photographs are not yet compared against live images.
