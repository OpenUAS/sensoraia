    Detailed Description

    Persistent std::thread pool implementing cv::parallel::ParallelForAPI.

    All batch state transitions (busy_, generation_, pending_workers_, worker resize/shutdown) occur under mutex_, while stripe indices within an active batch are claimed via next_task_ using guided chunk sizes matching OpenCV's stripe granularity. Nested or concurrent callers execute inline on the calling thread without blocking or oversubscribing workers.
