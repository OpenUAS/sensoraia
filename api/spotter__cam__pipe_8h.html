    Detailed Description

    Native USHER adapter for on-sensor detection or photo-only capture.

    Uses the neutral native-worker supervisor, then interprets only the matching detector sidecar. Capture success and usable analysis are separate outcomes; the last result is retrieved separately for EXIF.

    Precondition
    Configuration, capture, binding and result retrieval are serialized by the owning backend. This adapter has one parser workspace and one last result.
