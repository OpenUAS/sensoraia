    Detailed Description

    Native frame arithmetic and camera measurements; no codec or flight dependencies.

    Combined frames contain packed YUY2 followed by LE uint16 Kelvin*64. Display transforms never change these coordinates or original samples.

    Tiny1-C combined frame layout (width W, height H, W even):

    • Bytes [0, 2WH): YUYV image plane, Y0 U Y1 V per horizontal pixel pair; both pixels of a pair share U and V.
    • Bytes [2WH, 4WH): thermal plane, one little-endian uint16 per pixel in raster order. raw / 64 - 273.15 is degC as reported by the device; calibration is unverified. Codes 0 and 65535 are endpoint/invalid codes.

    Invariants: sizes are exact (lwir_frame_bytes()), all coordinates are native and unrotated, inputs are borrowed read-only and nothing is allocated. Live capture qualifies frames with lwir_frame_capture_valid() (and optionally lwir_frame_plausible()/ lwir_frame_settled()) before rendering or measuring; replay only needs lwir_frame_valid().

    Measurements have a scalar reference path; on little-endian ARM64 NEON processes eight-pixel blocks with identical results (exact integer averages, first-occurrence extrema), verified by parity tests.

    Optional conservative scene check; unusual valid scenes may be rejected.

    Rejects frames where more than 1% of image chroma bytes leave 120..136, the mean absolute horizontal luma step exceeds 45, or more than 10% of every-eighth-pixel thermal samples fall outside raw 14000..40000 (about -54..352 degC).

    Parameters
    frameBorrowed bytes.
    bytesAccessible size.
    widthNative width.
    heightNative height.
    Returns
    True for a structurally valid frame that passes all three heuristics.

    Optional conservative scene check; unusual valid scenes may be rejected.

    1. Chroma: every odd image byte is U or V; more than 1% outside 128 +/- 8 fails.
    2. Roughness: sum of |Y(x) - Y(x+1)| must average at most 45 per adjacent pair.
    3. Temperature: every eighth thermal sample; more than 10% outside raw 14000..40000 (about -54..352 degC, endpoint codes included) fails.
      Returns
      True when all checks pass. Unusual but genuine scenes may fail.

    True on success. No surface correction or object identity is inferred. False (errno untouched) for NULL pointers, invalid geometry or measurement, a size mismatch, or enabled thresholds with low >= high.

    Measure apparent device temperatures, keeping diagnostic coverage separate.

    Lines use integer Bresenham traversal of every center from start to end inclusive. Rectangles are visited in raster order; on ARM64 NEON handles eight-center blocks and scalar code handles the first column (when averaging), the right border and the tail. Results are built in a local copy and published only on success.

    Returns
    False for NULL pointers, invalid request/geometry, size mismatch or an empty threshold band; errno is not set.
