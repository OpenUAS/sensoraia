    Detailed Description

    Allocation-free, portable SHA-256 checksums for memory and streams.

    Use sha256_hex() or sha256_bytes() for a complete memory region. For a stream, initialize a context, append any number of chunks, then call exactly one finalizer. Reinitialize before hashing another message.

    Context storage belongs to the caller. Separate contexts can be used concurrently; sharing one context requires external synchronization. Inputs need no special alignment. The same digest bytes are produced on x86 and ARM64 without hardware crypto instructions or host-endian casts.

    Precondition
    Total input length must be less than 2^64 bits, as required by SHA-256.
    Warning
    A checksum detects changes but does not authenticate a producer.

    ◆ sha256

    typedef struct sha256 sha256

    Caller-owned incremental checksum state; treat members as read-only.

    The layout is retained for existing C and C++ consumers. Only buffer_counter bytes of buffer are valid before finalization; initialization deliberately does not clear unused buffer storage. No input pointer is kept.
