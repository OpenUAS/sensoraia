    ini_field_handler handler,
    void * context )
    		inlinestatic

    Destructively parse flat fields with blank lines and #/; comment lines.

    Precondition
    Buffer has at least length+1 writable bytes; callbacks retain no pointers.

    Rejects embedded NUL, sections and empty keys/values. The handler must reject unknown/duplicate keys and validate completeness after successful parsing. There are no quoting, escaping, multiline or inline-comment rules.
