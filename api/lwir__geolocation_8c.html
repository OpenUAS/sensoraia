    Detailed Description

    Native calibration and projection; no detector, JPEG codec or flight parser.

    Analysis builds only (LWIR_ENABLE_ANALYSIS=1). Provides a bounded, line-oriented calibration reader and a pixel-to-ground projection used on hotspots found in saved LWIR JPEG temperature planes. Fixed-size buffers only; no heap allocation. See lwir_geolocation.h for frame conventions and model limits.

    Load a calibration profile for one native image size.

    Load bounded projection calibration, requiring exact native dimensions.

    Reads key: value lines (a YAML-like subset) into a local copy and publishes it only after all checks pass, so geometry is never half-written. A bitmask of seen keys detects duplicates and missing required keys.

    Returns
    True for a structurally valid profile; false for I/O errors, a non-regular/empty/oversized file, syntax errors, duplicates, missing keys or out-of-range values.

    Project a native subpixel location onto the local ground plane.

    Project a native subpixel location using distortion, mount and observation pose.

    Steps:

    1. Validate every input (finite, in range, proper rotation).
    2. Pixel -> distorted normalized coordinates via intrinsics.
    3. Invert Brown-Conrady distortion by fixed-point iteration.
    4. Build the camera ray (x, y, 1), rotate camera -> body -> NED.
    5. Intersect with the plane agl_m below the navigation reference, starting from the lever-arm-offset camera origin.
    6. Convert the NED offset to WGS84 latitude/longitude via ECEF.
      Returns
      False for invalid inputs, an improper mount rotation, nonconvergent undistortion, a ray too close to the horizon, or a camera origin at/below the ground plane.
      Note
      Pixel coordinates are combined with cx/cy as-is, so they must follow the calibration's convention (OpenCV: integer coordinates at pixel centres).
