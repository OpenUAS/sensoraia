    Detailed Description

    LOOM-owned bounded feature validation and evidence serialization.

    Raw immutable buffers keep this core independent of libcamera and USHER process ownership. Valid feature transport is never navigation evidence.

    Precondition
    Inputs remain immutable and do not overlap the destination.

    Writes the LOOMNN02 format described in docs/exif.md. Invalid inputs leave output unchanged. The caller reserves this value in the JPEG's EXIF document; there is no filesystem access or feature-sized allocation here.

    Validate and decode an exact-sized binary record into bounded output.

    Precondition
    Inputs and writable outputs do not overlap; capacity is a float count.

    On failure count is zero; other outputs must be discarded. Structural validity is not a model match. Check identity against the JPEG capture record before consuming features. No buffer is retained or allocated.

    size_t count,
    const uint8_t * information,
    size_t information_size )

    Validate finite features against the shared IMX500 shape metadata.

    Parameters
    valuesBorrowed immutable float array for one exposure.
    countAccessible float count.
    informationBorrowed tensor-info bytes from that same exposure.
    information_sizeAccessible metadata bytes.
    Returns
    True for bounded, consistent shapes and finite values; false otherwise.

    Check shape products and cumulative length before reading values; rank/count limits bound both work and metadata access. No buffer is retained.

    Note
    This does not validate model semantics, feature similarity or a route.
