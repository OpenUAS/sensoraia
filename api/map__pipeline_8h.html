    Detailed Description

    Orchestrate orthophoto rendering, evidence, and final publication.

    Each output directory begins with an incomplete marker and is marked complete only after all required images and manifests have been finalized. Diagnostic runs intentionally retain incomplete status because they inspect imagery/coverage but do not pass the production publication gate.
