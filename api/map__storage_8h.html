    Detailed Description

    Integrity checks and bounded disk-backed intermediates for surveys.

    Checkpoints are identified by content hashes and published through fsync plus rename so resume can distinguish complete work from interrupted writes. SHA-256 here detects accidental mismatch; it is not an authenticity or security boundary.
