    Detailed Description

    Audio/pose adapter and zero-copy snapshot API for the EAR backend.

    Configuration and active-session functions belong to USHER's serial owner. Only snapshot solve/number/render/release are intended for the finalizer. Configure before initialization; drain detached workers before deinitialization.

    int ear_cam_pipe_finish ( struct ear_loudest_spot * result)

    Fuse the session into its final loudest-spot result and clear stored samples.

    Parameters
    resultDestination for the solved or invalid result.
    Returns
    Core solver status: 0 for an estimate, -1 for insufficient evidence or invalid arguments.

    Finalization consumes the session so the next survey cannot accidentally mix old and new flight legs. This legacy synchronous call solves committed samples and joins the log writer; it is not suitable for a latency-sensitive UART callback. Resolve pending poses first (ear_cam_pipe_solve() forces their fallback), and render before clearing samples. Prefer detach/solve/render/release for asynchronous sessions.

    ◆ ear_cam_pipe_record()

    int ear_cam_pipe_record ( const union dc_shot_union * shot)

    Associate the newest sound window with one flight-controller shot pose.

    Parameters
    shotFlight pose and shot number received from USHER transport.
    Returns
    0 when evidence is committed or admitted to the bounded pose queue; -1 for invalid input, unavailable/stale data or duplicate timed windows.

    Timed windows await pose evidence in a fixed queue for at most 200 ms; unresolved or legacy measurements retain their labelled request-pose fallback. Only the newest live measurement is read at each request, not every audio window. Capacity pressure retains the newest half of active samples, never a worker snapshot. Server recovery and CSV I/O run independently. This call never waits for them.
