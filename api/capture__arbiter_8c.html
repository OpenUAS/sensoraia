    Detailed Description

    Bounded camera-independent capture admission, coverage and timing evidence.

    The serial owner offers intentions; camera workers report acquired and published images. Public state access uses guard, and internal state helpers require that lock. No camera callback runs under it. File parsing happens before taking the lock so an invalid profile or sidecar cannot retain camera admission. An intention is not an image: only verified publication may credit coverage.

    ◆ capture_arbiter_load_camera()

    bool capture_arbiter_load_camera ( const char * filename)

    Load one camera's measured profile without guessing geometry from its ID.

    Parameters
    filenameBounded PANGEA_CAMERA_V1 flat key=value file; prefix c/a/l identifies the sensor.
    Returns
    True on acceptance; false with a diagnostic on invalid input or allocation failure.

    The first valid profile allocates the fixed ledger and random peer session. Replacing calibration is a startup operation, not a way to reinterpret existing coverage. Input is a nonempty regular file of at most 1 KiB containing one key=value per line. Blank lines and # comments are allowed; duplicate/unknown keys and invalid decimal fields are rejected without allocation. Invalid input leaves existing calibration and session state intact.
