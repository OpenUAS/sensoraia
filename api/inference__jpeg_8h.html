    Stream a JPEG into an open context's single declared image input.

    Parameters
    contextExclusive model owner; input storage and transform are written in place.
    filenameReadable regular JPEG, immutable throughout decoding.
    errorCaller-owned diagnostic buffer, cleared on success.
    capacityAvailable bytes in error, including its terminator.
    Returns
    True for complete, warning-free decoding and supported preprocessing.
