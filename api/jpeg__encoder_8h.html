    Detailed Description

    Encode BGRA map pixels and publish JPEGs with optional EXIF.

    The encoder owns and reuses its IJG workspace to avoid a new large output allocation for every tile. EXIF is inserted into the compressed stream, preserving encoded image bytes rather than decoding and encoding the pixels a second time.
