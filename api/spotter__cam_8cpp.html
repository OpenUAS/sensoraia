    Detailed Description

    Object-model decoder, detection sidecar writer and detector entry point.

    Camera/DMA/JPEG ownership belongs to imx500_camera.cpp. This application interprets retained frame metadata only as object boxes; it contains no LOOM feature processing, reference matching or waypoint policy. A structurally valid empty detection result is useful evidence and differs from missing or malformed inference; keep that distinction when extending the model contract.

    Zero on orderly EOF, two for malformed/out-of-order input, one for I/O failure.
