    Detailed Description

    Guarded retained-vector return processing and transactional T1 policy.

    Declared model vectors, aligned observation metadata and configured HOME produce bounded point proposals from explicitly declared model vectors. Outbound references are archived; reference-image matching is not implemented.

    struct camera_point_result * point )
    		static

    Interpret retained same-photo neural vectors under the declared return contract.

    Parameters
    frameCurrent saved AIcam photo and reference/model configuration.
    pointRequired destination in camera-point wire units.
    Returns
    False when model/pose/identity/direction validation rejects the photo.
    Warning
    Never replace no-match with the current pose, home position or guessed direction: those would look like valid navigation evidence on the FC.

    Generic embeddings are never guessed to be return directions. Only the PC simulation harness may turn them into an explicitly marked mock vector. The persistent owner subsequently limits movement and suppresses stale phases.
