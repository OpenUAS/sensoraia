    Detailed Description

    Load fixed-session photos and render Simple/Great map pixels.

    Great computes seam ownership once from a bounded global overview, then reuses that plan for every output tile. Global decisions avoid seams changing at tile borders; full-resolution footprint fallback preserves narrow source coverage that a coarse overview might miss.
