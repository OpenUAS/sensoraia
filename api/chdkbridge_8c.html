    Detailed Description

    Standalone USB PTP client for CHDK JPEG capture and normalized zoom.

    One invocation owns one USB interface and PTP session. Standard PTP framing carries CHDK vendor commands; small Lua scripts execute on the camera, not on the host. USB access uses Linux usbfs directly (usbfs.h); no USB library is loaded. This standalone C client implements camera control directly over USB PTP.

    Warning
    A failed transaction is not retried: capture or lens movement may already have occurred. Fake-USB tests are not physical-camera validation.
