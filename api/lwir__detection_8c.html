    Detailed Description

    Pose-free thermal components using caller-owned bounded scratch storage.

    Analysis builds only (LWIR_ENABLE_ANALYSIS=1). Operates on the exact native Kelvin*64 plane recovered from a saved LWIR JPEG. Algorithm outline:

    1. Robust frame statistics: exact median (background) and median absolute deviation (noise) via 65536-bin histograms, so no sorting buffer is needed.
    2. Global threshold combining an absolute floor with a robust rise over background.
    3. 8-connected flood fill (breadth-first) of above-threshold pixels.
    4. Per component: local background, contrast gate, excess-weighted subpixel centroid and shape features.
    5. Keep the top two generic and top two tray-like components; report trays if any.

    Cost trade-off: every component clears and scans the full 65536-bin histogram for its local median, so frames with many small components cost roughly 65536 operations per component in addition to the per-pixel work.

    Ranking predicate for retained candidates.

    Generic order: higher contrast first, then larger excess heat. Tray order: larger excess heat first (presumably favouring an extended hot tray over a small very hot point), then contrast. A full tie returns false, so the earlier-found component (row-major seed order) keeps its place.

    Parameters
    candidateNewly evaluated component.
    currentRetained component it is compared against.
    tray_orderSelect the tray ordering instead of the generic one.
    Returns
    True when candidate should rank strictly above current.

    Exact median of the values counted in the histogram.

    Walks the cumulative count once to find the lower and upper middle ranks; for an even count the result is their mean, so it can end in .5. Exact for integer inputs, avoiding a sort and a pixel-sized copy.

    Parameters
    workspaceScratch storage whose histogram holds exactly count samples.
    countNumber of samples; must be at least 1 ((count - 1) would wrap).
    Returns
    Median value in histogram-bin units.

    Detect and rank hot connected components in a native temperature plane.

    Rank native thermal components without touching hardware, pose or files.

    See lwir_detection.h for the contract and the file overview for the algorithm. All arithmetic stays in raw Kelvin*64 codes until results are converted to Celsius (code / 64 - 273.15); temperature differences convert by dividing by 64 only.

    Returns
    True for a valid plane (even with zero candidates); false for invalid arguments.
