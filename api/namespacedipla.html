    ◆ apply_flight_margin()

    void dipla::apply_flight_margin ( Waypoints & route,
    unsigned margin_cells )

    Apply the configured horizontal flight margin.

    Both planners pass here once before publication. The inset is an application policy, not model normalization or a change to the raw sampler. Validate the entire route, including Z, before changing any coordinate.

    See also
    Network::sample

    Raw model outputs remain unchanged until the application prepares a flight route. The default two-cell inset clips XY to 4..96 metres without modifying model Z.

    Parameters
    routeComplete finite route to constrain in place.
    margin_cellsHorizontal inset in grid cells, inclusive range 0..24.
    Exceptions
    std::runtime_errorIf the margin is invalid or any coordinate is nonfinite.

    ◆ initialize_runtime()

    void dipla::initialize_runtime ( const std::string & onnx_lib_path)

    Load the ONNX Runtime C API before constructing an inference session.

    Delegate runtime discovery to the shared loader so Diplacam uses the same library-selection and process-lifetime rules as other ONNX consumers. Keeping an error buffer here turns the C API's bounded diagnostic into a C++ exception before a Network can acquire a session from an unavailable runtime.

    See also
    Network::Network

    Searches executable-relative directories in order, trying architecture-specific runtime names before generic names on ARM64. The optional directory is searched last and is normally resolved from the model settings INI by the application entry point. The loaded handle is retained for process lifetime so every shared session retains a valid runtime API.

    Parameters
    onnx_lib_pathOptional final directory to search; empty skips it.
    Exceptions
    std::runtime_errorIf no candidate exists, cannot load, or exposes an incompatible API.

    ◆ serve()

    int dipla::serve ( int descriptor,
    const std::string & config,
    const std::string & default_model,
    const std::string & default_metadata,
    bool cmaes = false,
    const CmaesOptions & comparison = {},
    const NetworkOptions & network_options = {},
    const ExperimentOptions & experiment = {} )

    Serve a Diplacam session over an already-connected IPC descriptor.

    Starts one planning thread and services requests on the calling thread. One GP owner consumes each accepted observation once. Queue overflow fails closed. START during an active survey requests a new retained chunk; its first accepted pose anchors field centre (50,50). Active START retains that frame and belief; STOP followed by START resets both. Complete-route replies copy one generation; legacy retrieval pins a route across eight points. The caller retains descriptor ownership and should close it after this returns. Reply backpressure fails the connection instead of blocking request handling.

    Parameters
    descriptorConnected socket descriptor; ownership remains with caller.
    configWorker INI containing field, cadence and planning-pose age settings.
    default_modelDefault model path supplied by the executable settings/CLI.
    default_metadataDefault metadata path supplied by the executable settings/CLI.
    cmaesSelect the explicit comparison-only planner; false uses diffusion.
    comparisonBounded CMA-ES options used only when cmaes is true.
    network_optionsDescriptor and bounded ONNX execution policy, ignored in comparison mode.
    experimentStartup GP, synthetic sensor, seed and flight-margin policy.
    Returns
    Zero after orderly transport and worker shutdown; nonzero on failure.
    Exceptions
    std::exceptionFor invalid configuration or unrecoverable setup errors.
    Note
    Computational validity is not route execution or field accuracy. This worker neither publishes GCS moves nor changes navigation blocks.
