    Detailed Description

    JPEG encoding and durable no-overwrite publication of LWIR frames.

    Final stage of the LWIR capture pipeline. Acquisition and frame arithmetic (lwir_frame.h) yield an immutable frame, the renderer (lwir_render.h) converts it into display rows, and this module wraps those rows in a JPEG together with the evidence needed to interpret it later. Frame arithmetic never depends on this module.

    Input frames:

    • Combined (LWIR_COMBINED): packed YUYV display plane followed by an equally sized little-endian Kelvin*64 temperature plane; see lwir_frame_bytes().
    • Image-only (LWIR_YUYV_IMAGE, TDK device): the limited-range YUYV plane alone, half the combined size, with no temperatures.

    JPEG output, produced by the bundled IJG libjpeg 9f (lwir_jpeg_provider()):

    • APP14 "LWIREV02" key=value provenance text, when evidence is supplied.
    • APP1 EXIF holding the sensor-capture record, for live frames only.
    • APP15 chunks carrying the exact native temperature plane, signed "LWIRRAW1" (live) or "LWIRSIM1" (synthetic replay); see lwir_container.h.
    • Sequential scan, 4:4:4 sampling, quality 1..100 (0 means legacy 100).

    Invariants:

    • Temperatures survive bit-exact at any JPEG quality; only the display is lossy.
    • Image-only frames carry no thermal markers and are expanded from limited to full-range YCbCr before encoding.
    • Publication never replaces an existing path and is durable on success.
    • Encoding uses one static workspace: single-threaded and not re-entrant.

    Encode into an existing stream without owning its publication policy.

    Parameters
    outputCaller-owned writable stream; caller handles flush/sync/close.
    frameImmutable combined frame, or packed YUYV when evidence selects LWIR_YUYV_IMAGE.
    bytesExact frame size.
    widthNative width.
    heightNative height.
    syntheticWhether thermal evidence is simulated.
    evidenceOptional capture provenance; required for display orientation.
    renderOptional display policy; NULL keeps the sensor image.
    Returns
    True on successful encoding. Discard partial output on failure.

    Serial encoder, bounded scanline workspace. The codec may allocate internally. Image-only evidence permits sensor-view rendering only, expands limited-range YUYV for JPEG, and emits no thermal markers. Otherwise JPEG display is lossy; embedded native temperatures are exact.

    Failures set errno: EINVAL for bad arguments, quality above 100 or display orientation without evidence; ENOTSUP for image-only frames combined with thermal rendering, synthetic output or thermal evidence; ENOSPC when the provenance text does not fit its fixed buffer; EIO for codec failures. Renderer failures keep the renderer's errno.

    Note
    A NULL render, or jpeg_quality 0, encodes at the legacy quality 100.
    Warning
    Uses process-wide static encoder state: never call concurrently or from a signal handler.

    Encode into an existing stream without owning its publication policy.

    Image-only frames are half the combined size. Layout values beyond the known enum are rejected rather than guessed. A NULL render becomes the plain sensor view with quality 0, i.e. legacy 100.
