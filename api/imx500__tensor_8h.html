    Detailed Description

    Shared IMX500 tensor-info wire layout and bounded decoding policy.

    The object detector and LOOM interpret the same driver metadata. Keeping the offsets here prevents their camera ABI definitions drifting apart; model-specific interpretation remains with each consumer.
