    Detailed Description

    Write georeferencing sidecars for rendered Pangea map images.

    The world file and PAM metadata use different origin conventions: the world file identifies the centre of the upper-left pixel, while the GeoTransform identifies its outer corner. Keeping both values derived from the same map grid prevents GIS readers from shifting the image by half a pixel. Sidecars are published without overwriting prior work so a failed run cannot silently replace metadata belonging to another map.
