    Detailed Description

    C++ value interface with explicit conversions and OpenCV JSON I/O.

    Copy construction/assignment are deep; lookup-produced handles share a selected node until copied or rebound. Conversion failures throw rather than silently turning missing, differently typed or out-of-range data into defaults.

    Note
    Allocation failures may additionally propagate standard-library exceptions.
