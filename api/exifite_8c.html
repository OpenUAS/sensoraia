    Detailed Description

    Allocation-free EXIF parsing, serialization and bounded JPEG streaming.

    The implementation keeps three jobs separate: validate borrowed TIFF bytes, collect caller-owned values, then stream JPEG markers around a serialized APP1 payload. That separation lets us check each boundary without allocating image-sized buffers or interpreting manufacturer-specific pointer structures.

    See also
    exifite.h for public contracts and storage ownership.
