    Detailed Description

    Bounded, two-pass JSON parsing and iterative DOM operations.

    Validation and materialization deliberately share the same grammar. A counting pass establishes exact record/text requirements before one backing allocation is split into aligned records and byte strings. Writers and copies likewise reuse a single walker so their sizing and output passes agree.

    Implementation invariants
    Cursors never exceed their extents; arithmetic is checked before advancing. A NULL pool/output base means measurement, not allocation failure. Fixed traversal frames replace recursion, and all per-call state remains local. The API still requires accessible, stable input and DOM pointers: structural checks cannot make arbitrary addresses safe to dereference.
    See also
    jsonbourne.h for public ownership, argument and return-value contracts.
