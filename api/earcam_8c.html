    Detailed Description

    ALSA acoustic detector for motionSCOUT-style narrow-band alarm tones.

    EARcam captures mono PCM, isolates the configured frequency band with cascaded Butterworth biquads, measures a bank of Goertzel tone bins over short Hann windows, and emits either an operator display or machine-readable samples for USHER. The process remains independently useful for bench work and deliberately keeps the USHER server protocol simple: newline-delimited output plus STOP/QUIT input.
