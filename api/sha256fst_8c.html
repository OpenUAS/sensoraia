    Detailed Description

    Portable SHA-256 block compression, streaming and digest formatting.

    Implements the SHA-256 operations from FIPS 180-4 using unsigned 32-bit arithmetic. Input words and output bytes are explicitly big-endian; neither pointer alignment nor the host byte order affects the result. Complete input blocks bypass the context buffer. The compression schedule occupies a fixed 256-byte local array; no heap or mutable global state is used.

    Parameters
