    ◆ condition()

    void dipla::aigenlib::condition ( Matrix & covariance,
    Vector * mean,
    const Sensor & sensor,
    const Vector * measurement )

    Condition a GP in place with optional measurement assimilation.

    Both mean and measurement must be supplied, or both null for look-ahead. All shapes, indices, noise and input finiteness are checked before mutation. Workspace is two m-by-n matrices, small solver storage and one 4 KiB scratch tile per active lane, never an n-by-n product temporary. Large multi-row updates use at most three lanes and join before symmetry restoration; a thread-creation failure falls back to remaining serial work. A single-row observation fuses updating and symmetry restoration without scratch; both triangle calculations and their averaging order are preserved exactly. Arithmetic overflow throws; after mutation begins it does not roll back the belief. Concurrent access requires caller synchronization.

    Parameters
    covarianceSquare finite covariance, updated in place.
    meanOptional finite cell mean, updated in place.
    sensorAveraging operator.
    measurementOptional finite measurement values.

    ◆ solve_symmetric()

    Matrix dipla::aigenlib::solve_symmetric ( const Matrix & system,
    const Matrix & right,
    SolveMethod * method = nullptr )

    Solve a finite symmetric system with multiple right-hand sides.

    Cholesky is attempted first. On failure, bounded cyclic Jacobi sweeps compute a spectral pseudoinverse with abs(lambda) > 1e-15 * max(abs(lambda)). Negative eigenvalues retain their sign. Input is scaled before factoring; neither input is mutated. Symmetry is checked relative to matrix scale and the lower triangle defines the system within that tolerance. Zero systems produce zero solutions. Throws on invalid shape, nonfinite data, numerical overflow, or nonconvergence; never silently adds jitter. Not a general SVD.

    Parameters
    systemSquare coefficient matrix, including 0-by-0.
    rightMatrix with system.rows() rows, possibly zero columns.
    methodOptional output reporting the selected factorization.
    Returns
    Owning solution with the same shape as right.
