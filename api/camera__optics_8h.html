    Detailed Description

    Optical profiles and EXIF settings for simulated survey cameras.

    The Pi AI profile is a deterministic rendering model, not a measured calibration. Its crop, field of view, distortion, and channel scales must stay coupled so the saved image and intrinsics describe the same pixels.
