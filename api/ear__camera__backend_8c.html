    Detailed Description

    EAR-owned survey admission, finalization and generic point completions.

    USHER's serial owner calls lifecycle/configuration/poll hooks. One joinable worker solves immutable snapshots and writes evidence; it never owns UART or live pose lookup. A small wake channel signals mailbox state, not data.
