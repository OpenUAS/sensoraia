    Detailed Description

    Reusable numeric tensor sessions without image, acoustic or planning semantics.

    Cancellation is cooperative; outer worker supervision remains the recovery boundary.

    Validate graph contracts and bind reusable caller buffers; failure releases acquired resources.

    Parameters
    sessionZero-initialized owner with no open session; do not copy it after opening.
    modelReadable ONNX graph path.
    inputsNamed input views whose backing buffers outlive the session.
    input_countNumber of input views, in 1..ONNX_TENSOR_LIMIT.
    outputsNamed writable output views with the same lifetime rule.
    output_countNumber of output views, in 1..ONNX_TENSOR_LIMIT.
    optionsOptional execution/search policy; NULL uses one CPU thread.
    errorWritable failure diagnostic, cleared on success.
    capacityAvailable bytes in error.
    Returns
    True only after every name, type, shape and backing byte count is accepted.
    Note
    Dynamic graph axes bind to the declared concrete shape; outputs are checked again after each run.

    Parameters
    sessionOpen owner; one run at a time is admitted.
    deadline_usAbsolute completion budget in the host monotonic clock domain.
    errorWritable failure diagnostic, cleared on success.
    capacityAvailable bytes in error.
    Returns
    True for complete execution with valid output shapes and an unexpired budget.
    Warning
    Ignore output buffers on false. Cancellation is cooperative, not a hard deadline.
