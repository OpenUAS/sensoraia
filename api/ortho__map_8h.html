    Detailed Description

    Describe the validated photo set and render projected map windows.

    Rendering retains source provenance and a per-pixel confidence class alongside colour so publication can distinguish observed colour from completion. The API keeps rendering separate from JPEG/XYZ publication, allowing both output formats to share the same map engine.
