    Detailed Description

    One-window acoustic inference worker with source-time and measured-level evidence.

    The capture thread never shares its live sample buffer with ORT; stale generations are discarded.

    Select the explicit detector and qualify an ONNX PCM contract before capture starts.

    Parameters
    settingsEARcam application settings path.
    rateExact capture sample rate; no implicit resampling is performed.
    enabledSet true for ONNX, false for a successfully selected native detector.
    errorWritable failure diagnostic.
    capacityAvailable bytes in error.
    Returns
    True for an accepted native or ONNX selection; false never means native fallback.
    Precondition
    No inference thread or previously configured model is active.

    ◆ ear_inference_push()

    void ear_inference_push ( const int16_t * samples,
    size_t count,
    uint64_t end_us,
    uint64_t error_us )

    Supply capture samples without waiting for model execution or a busy model mailbox.

    Parameters
    samplesBorrowed signed mono PCM; no pointer survives this call.
    countNumber of samples in this continuous capture chunk.
    end_usCapture end of the chunk in CLOCK_MONOTONIC microseconds, or zero when unknown.
    error_usBound on capture-window timing uncertainty, not inference duration.

    Complete windows may replace pending work; overload loses evidence rather than blocking ALSA.

    Precondition
    One capture producer owns push/discontinuity calls until stop begins.
