    Detailed Description

    Small path and writable-directory helpers shared by USHER backends.

    Paths are intentionally resolved only for a leading ~: USHER configuration is not a shell and must not expand arbitrary variables or execute shell syntax.

    int usher_publish_photo ( const char * source,
    const char * destination )
    		inlinestatic

    Publish completed immutable bytes atomically without copying or replacing an existing file.

    Parameters
    sourceExclusively owned, nonempty regular file with no other hardlinks.
    destinationPublic path on the same filesystem.
    Returns
    0 for durable publication and private removal; 1 if published but directory sync or private removal failed; -1 if not published, with errno describing the failure.

    Call only after every metadata write. Readers may open the final name immediately. A positive result must never trigger a capture retry or another write to either alias. Crash recovery may retain a private alias; callers must not modify published originals.
