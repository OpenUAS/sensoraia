    Admit a target only after its owner's coordinate application succeeds.

    Parameters
    targetsExclusive target store.
    observationImmutable valid geographic observation.
    applyOptional coordinate transaction; false leaves the selected slot unchanged.
    contextBorrowed callback state.
    Returns
    Assigned zero-based slot, or minus one for invalid/nonimproving/rejected observations.

    Empty slots fill first; once full, only a strictly better score replaces the lowest. Reobserving exactly the same position improves its existing slot instead of consuming another.
