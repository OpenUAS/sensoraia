    Detailed Description

    Native host tool for LWIR lens and camera-mount calibration.

    Lens mode estimates pinhole intrinsics and five Brown-Conrady distortion coefficients from varied checkerboard photographs. Mount mode holds those intrinsics fixed and estimates camera-to-body rotation from a board physically aligned with the aircraft datum. Keeping these stages separate avoids interpreting lens distortion as a mounting error.

    OpenCV supplies detection, geometry and drawing; bundled libjpeg handles JPEG I/O so no OpenCV imgcodecs module or additional codec dependency is needed. Original pixels are neither resized nor EXIF-oriented before fitting: coefficients must describe the same native coordinates used by LWIRcam. Only inspection previews are enlarged and annotated.

    Each run produces a runtime-readable profile, a diagnostic report and inspection previews. Failed runs remove the candidate profile but retain available diagnostic evidence. Outputs are intended for a trusted workshop directory, not concurrent writers competing for the same filenames.

    Warning
    Numerical convergence is not physical verification. Every exported profile remains unverified; corner orientation, board alignment and independent measurements must be checked before relying on projected coordinates.
