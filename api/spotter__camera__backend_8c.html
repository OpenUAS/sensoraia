    Detailed Description

    Native Spottercam backend and optional C11 UART target-slot projection.

    Projects validated vehicle detections through a measured PANGEA_CAMERA_V1 pinhole profile onto the five ranked geographic target slots (0..4 -> T1..T5) and publishes correlated USHER_CAM_POINT_UPDATE frames without Python helpers.
