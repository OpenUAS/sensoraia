    Detailed Description

    Eigen-style Aigen values and build-selected planner aliases.

    Aigen always uses aigenlib and can coexist with Eigen in one translation unit. The planner aliases follow DIPLA_USE_EIGEN consistently across units. Supports a small value API, not Eigen's general expression templates.
