    Detailed Description

    Decode JPEGs with IJG scanlines into BGRA previews or disk-backed rasters.

    Streaming one scanline at a time avoids retaining both the compressed source and a full decoded frame in memory. The working raster is an internal lossless intermediate. Its bounded raster path rejects progressive JPEGs; preview decoding retains the codec's progressive support.
