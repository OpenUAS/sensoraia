    Detailed Description

    Resumable, resource-bounded USHER photo-map assembler.

    Consumes clean USHER JPEGs, validates pose/geometry provenance, and incrementally blends them into checksummed map tiles. Atomic state/checkpoint files allow interrupted runs to resume. MIMIC and explicit real-camera profiles are separate input modes; this flat-ground renderer does not certify map accuracy.
