    Recompute an EAR loudest-spot result and emit decorated/field JPEGs.

    Parameters
    argcCommand-line argument count.
    argvExpects a session CSV and destination JPEG, or a help/version switch.
    Returns
    0 on completed output, 2 for usage errors, or 1 when the log has no valid solve.

    The undecorated sibling preserves clean heat colors for later map overlay; the decorated JPEG remains the human-readable result and both share one .geo frame.

    Decode one EAR session row into the shared fusion sample structure.

    Parameters
    lineComma-separated log row in the order documented by the session header.
    sReceives the parsed measurement; the caller owns this sample slot.
    Returns
    0 for all twelve required fields, or -1 for an incomplete/malformed row.

    Keeping replay on ear_sample makes the same solver and renderer handle recorded evidence and live USHER snapshots.
