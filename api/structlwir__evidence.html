    Detailed Description

    Borrowed provenance for one publication; strings must outlive encoding.

    User labels, post-frame state and unknown exposure timing stay distinct. Every field is copied into the APP14 text as-is; nothing here is validated against the device. NULL strings are recorded as fixed placeholders so a reader can tell "not supplied" from an empty value.
