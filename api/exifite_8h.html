    Detailed Description

    Bounded C11 EXIF metadata and JPEG streaming interfaces.

    EXIFite covers Sensoraia's metadata without a general-purpose TIFF object graph. Callers own the storage so memory use stays predictable on MORA. Readers borrow bytes; writers collect little-endian values before producing one JPEG APP1 payload. No function decodes or recompresses image pixels.
