    Detailed Description

    Sensor-independent acoustic samples and ground-source estimates.

    Supply geotagged audio windows from any capture adapter. This API does not acquire audio, own a flight session, or know about USHER/UART. Positions and heights must use a consistent navigation reference; the solver cannot repair microphone gain changes, unsynchronized poses or bad terrain data.

    Estimate a ground source from relative loudness along a survey track.

    Parameters
    samplesCaller-owned immutable windows; never modified or retained.
    countInput count, bounded by EAR_MAX_SAMPLES.
    resultRequired destination; cleared before validation when non-NULL.
    Returns
    Zero for an estimate, -1 for invalid input or insufficient retained evidence.

    A robust centroid seeds a damped inverse-distance fit; unstable fits fall back to that centroid. Shared bounded scratch storage is mutex-protected, so concurrent calls serialize without allocating another survey-sized buffer.

    Warning
    A valid result is not an absolute alarm gate. With too few alarm windows the solver deliberately uses other finite levels, even silent ones. Mission policy must consider level, quality, geometry and independent evidence. The legacy near-zero-latitude placeholder gate also excludes equatorial tracks.
