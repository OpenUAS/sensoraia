    Detailed Description

    Header-only C++17 value adapter around OpenCV's JSON persistence layer.

    OpenCV remains the parser and ordinary writer. Normalization carries null, booleans and 64-bit integers through reserved string markers so those types are not lost in FileStorage's representation. Nodes are then detached from FileStorage into a heap-backed tree usable by existing C++ consumers.

    Ownership and mutation
    Ordinary Value copies recursively clone their trees. Child lookups and items() initially return shared child handles instead, allowing a selected child's mutators to affect its parent. Copying such a handle creates an independent tree; assigning a new Value to the handle rebinds the handle, not the parent slot.
    Deliberate limits of this adapter
    This is not JSONbourne's bounded arena API: strings, maps, vectors and shared nodes allocate, while cloning, conversion and serialization recurse. No fixed nesting or allocation budget is imposed here. Objects use unique sorted map keys rather than retaining duplicate members or their original source order.
    Precondition
    Application string/key data must not use the reserved __USHER_OPENCV_JSON_ namespace, which belongs to the transport representation.
    Note
    OpenCV acceptance and this adapter's normalization determine accepted input; this wrapper is not an independent strict RFC 8259 validator.
