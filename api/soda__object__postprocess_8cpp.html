    Detailed Description

    EXIF-driven object-hit post-processing for SODA.

    This component does not run inference. It reads USHER's object record, creates sibling review copies and a padded crop, and appends one CSV row. The original flight JPEG is never changed.

    bool soda_process_object_detection ( const char * image_path)

    Post-process a captured image for an object-detection hit, if it has one.

    Create SODA review derivatives only when the source EXIF describes an object hit.

    Returns
    True for no-op/no-hit or complete processing; false when a detected hit could not be fully copied, cropped, or recorded.
